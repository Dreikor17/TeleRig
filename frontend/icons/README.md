# TeleRig's own icons

These few icons were drawn for TeleRig (24x24, 2 px round strokes, to sit next to the Lucide set in
`frontend/vendor/lucide/`). They are part of the app and carry its license (AGPL-3.0-only).
`tools/build_icons.py` puts them into the same inline sprite as `i-<name>`.

| file | used for |
|---|---|
| `tr-bridge.svg` | the WSJT-X bridge button (two devices joined by wires) |
| `tr-fullscreen.svg` / `tr-fullscreen-exit.svg` | full screen on / off |
| `tr-pause.svg` / `tr-play.svg` | pause / resume transmit over the bridge |
